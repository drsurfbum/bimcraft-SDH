## Behavior

Properties can preview a browser source without opening it. Its source-specific controls now require the **rendered source ID and editor owner** to match the active drawing. Until then, the control explains: “Open the source shown in Properties to use its actions. Double-click it in Project Browser or press Enter.” Hover, focus/Enter and touch expose the explanation without running an edit or export.

The shared adapter checks both availability and execution. The Properties palette retains its own target while a field has focus; it does not substitute a newer browser selection. The same guard covers sheet editing, schedule CSV, projected-view settings and retained detail/scale inputs. A new editor resets the palette binding even when source IDs or display names repeat. Ribbon, File and bottom controls continue to target the active drawing, independently of browser selection. No model operation, journal, source format, renderer or export implementation changed. Visual verification also corrected the first-open native schedule selector: its value is now applied after the schedule options exist, with a regression asserting the selector agrees with the actual active source.

## Regression coverage

- Active C-101 / displayed C-102: Properties editing is unavailable and opens only an explanation; no sheet or journal change. Ribbon Edit sheet still opens C-101.
- Activate C-102: Properties editing enables, opens C-102, and saves only that sheet ID.
- Give both sheets exactly the same number/title through the native editor: selecting the other source still refuses editing (including a real touch explanation). After activation, an edit changes only the intended ID.
- Active assembly schedule / displayed material legend: Properties CSV is unavailable; Enter opens an explanation and downloads nothing.
- File CSV still downloads the authoritative active assembly schedule. Activate the legend: Properties CSV enables and downloads the exact authoritative legend contents. Both CSV files are compared in full, not only by filename.
- Focused adapter test also checks duplicate schedule labels, foreign-editor ownership with the same source ID, busy state, and retained Properties settings. The same new regression fails against the exact reviewed adapter and passes after the fix.

The browser helper uses fresh contexts, real IFC records, native sheet editing and actual downloads. For focusable `aria-disabled` controls, real pointer/touch input is preceded by a DOM hit-test; it does not use forced clicks, synthetic successful exports, or clicks through dialogs. Existing recovery and unsupported-record assertions remain.
