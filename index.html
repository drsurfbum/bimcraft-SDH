Start with the house and the Mac

One active implementation slice at a time. Discovery and comparison do not adopt upstream code. Proposed navigation changes require review before dependent semantics are committed.

  1. R00-A · Pin the baseline and preserve comparison builds
    Exact commits, fixture hashes, hardware/build configuration and source/runtime evidence ledger; one active implementation slice, owner and isolated checkout recorded.
  2. R02-A · Compare house imports and explain every omission
    Both original exports, release/candidate results, source-product identities and reasons for omissions; compare missing roof geometry and materials without changing masters. Record memory/time and original-file refusal.
  3. R01-A · Prototype native Mac trackpad navigation
    Review proposed mapping before committing dependent semantics. Verify pan/zoom/orbit, selection, panel scroll, cancellation, context click and momentum on the actual Mac.
  4. R03-A · Prove model/history ownership and agent parity
    Manual/core/real MCP edits agree; stale/dirty/wrong-document interleaving cannot modify or Undo unrelated work; independent saved-file checks, rollback and receipts.
  5. R02-B · Fix the smallest verified import failure
    Choose the defect from measured comparison, provide a synthetic reproducer and upstream-compatible correction, then rerun affected house and unsupported controls.
  6. R02-C · Large-file import and persistence lifecycle
    Document an explicit resource policy instead of merely deleting MAX_FILE. Exercise below/at/above thresholds, original files, native save/open, autosave/recovery and links, peak memory, UI responsiveness, cancellation and failure rollback. Exact 256 MiB is currently refused.

What the audit established

Development direction has changed

New BIMCraft Web development is frozen. Accepted work and both draft candidates remain available for handoff; no maintainer contact or feature merge has occurred.

A head start, with important gaps

Rust already supplies CLI/MCP, model commands, hosted components and documentation tools. Compound-wall behavior, framing coordination and complete IFC preservation still need work.

The 256 MiB cap is application policy

It is checked before parsing, not an IFC or Rust language limit. Large-file work must also cover save/reopen, autosave and recovery.
